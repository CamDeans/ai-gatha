# Deansight AI

A production-ready Next.js web application for AI-powered image generation using Stable Diffusion.

## Features

- 🎨 AI Image Generation with Stable Diffusion
- 🔐 Secure Authentication System
- 💾 MongoDB Integration
- 🌓 Dark/Light Theme Support
- 📱 Responsive Design
- 🖼️ Image Gallery
- ⚙️ User Settings Management

## Tech Stack

- **Frontend**: Next.js 14, React, TailwindCSS
- **Backend**: Next.js API Routes
- **Database**: MongoDB
- **Authentication**: NextAuth.js
- **AI Model**: Stable Diffusion
- **Styling**: TailwindCSS with Amazon-inspired theme

## Prerequisites

Before you begin, ensure you have:
- Node.js 18+ installed
- MongoDB Database instance
- GPU for Stable Diffusion (local or cloud)
- Git installed
